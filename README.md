# Jogo de Vestir da Barbie

Um jogo de vestir inspirado nos clássicos jogos de moda da Barbie, desenvolvido como projeto de aprendizado em Desenvolvimento Web.

O projeto está sendo construído com HTML, CSS e JavaScript puro, com foco em praticar estrutura de páginas, estilização, manipulação do DOM, eventos, animações e lógica de programação.

## Acesse o jogo

[Jogar online](https://laraborges300-droid.github.io/Jogo-de-Vestir-para-Meninas/)

## Repositório

[Ver código no GitHub](https://github.com/laraborges300-droid/Jogo-de-Vestir-para-Meninas)

## Funcionalidades atuais

- Personagem interativo
- Armário de roupas
- Troca de roupas
- Efeito de dissolução durante a troca de looks
- Sistema de looks surpresa
- Efeito de brilho nos looks surpresa, que será aprimorado para o efeito Pixie Dust
- Efeitos de interação ao passar o mouse sobre as roupas
- Interface inspirada em jogos clássicos de vestir
- Layout desenvolvido em proporção 16:9
- Favicon personalizado

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## Objetivo do projeto

Este projeto faz parte do meu processo de aprendizado em Desenvolvimento Web e Sistemas de Informação.

A proposta é aprender na prática conceitos de HTML, CSS e JavaScript através da construção de uma aplicação interativa, enquanto desenvolvo e aprimoro minhas habilidades de programação.

## Em desenvolvimento

O projeto ainda não está finalizado e continuará recebendo atualizações.

Entre as funcionalidades e melhorias planejadas estão:

- Nova categoria de roupas (especiais)
- Mais opções de looks
